Privacy · Updated 8 September 2026

Your notes stay with you.

Notryn keeps your workspace local. This page explains what stays on your computer and when an external service is involved.

The app

Notryn reads and writes the folders you choose to connect. Settings, recovery data and app-created Brains are stored locally. Normal note-taking does not send your notes to Notryn or to an AI provider.

Installing or checking for updates connects to GitHub to fetch release information and packages. Public downloads do not need a GitHub login. GitHub handles those requests under its privacy statement.

If you give another tool access to your Markdown files, its use of those files is governed by that tool and the permissions you grant. Keeping notes locally is not a claim that the app encrypts them; use your computer's access controls and backups.

This website and demo

This website does not add advertising or analytics scripts. The demo uses fictional notes bundled with the page and does not ask for access to your computer's folders.

The website may retain your interface theme in local storage. Demo notes and edits stay in memory and reset when the page reloads. Clearing this site's browser data removes saved preferences.

The site is operated by Pedro Teixeira and hosted on GitHub Pages. GitHub receives web requests, including IP address and browser information, under its privacy statement linked above. GitHub controls its own security logs and retention. We do not add visitor analytics or advertising cookies. Release download counters include repeated downloads and updates; they do not identify completed installs.

Messages and support

Do not include private notes, passwords or access tokens in an issue or support message. Messages sent to the project are used to respond to your request. Public issues remain visible in the GitHub project until removed. Private security reports are restricted to the people involved in handling them. Contact Pedro Teixeira through the project for questions or deletion requests concerning project-controlled information; GitHub account and platform data requests are handled by GitHub.
