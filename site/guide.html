Install Notryn · 0.2.0-beta.6

Make yourself at home.

Install the desktop app from your terminal. Your notes stay on your computer, in folders you control.

LinuxmacOSUpdateUninstall

Linux / Omarchy

For x86_64 computers. The package includes the app and local server. You do not need to install Python or Node.js. Use your normal user account, without sudo.

Save your notes and quit an older Notryn, then run:

curl -fsSL https://notryn.com/install.sh | sh

Follow the download percentage, size and speed in your terminal. Each installation step shows its activity and confirms when it is done.

No GitHub account is required. If the domain is unavailable, use the versioned GitHub installer.

Notryn opens in its own window and appears in your application menu. The app runs locally; the developer's Mac does not need to stay online.

When you create a Brain, Notryn asks where to put its folder and shows the complete path before creating it.

If your terminal does not recognise notryn, use ~/.local/bin/notryn. You can also add ~/.local/bin to your shell's PATH.

macOS

Use the same command above. The installer selects Intel or Apple silicon and puts Notryn.app in your user's Applications folder.

This is an experimental beta build with an ad-hoc signature. Apple Developer ID signing and notarization are not ready, so macOS may block a download. Do not disable Gatekeeper to install it. The finished Mac release will follow a fresh download test with Apple signing.

Update

Save your notes, quit the app, then run:

notryn update

Open it again with notryn. Updates check the download and new local server before replacing the app, keeping the previous version. Your notes and settings stay separate. Beta installations receive newer preview releases and then stable releases. Stable installations only receive stable releases. No GitHub login is required.

Updating from beta.4 or earlier? Your current updater uses the old display once more. Run the installation command above to get the new progress display right away; it updates your existing app too.

Already using alpha.2? Run the installer above once. The real update command starts with alpha.3.

Go back to the previous version

notryn rollback

Close the app first. This restores the previous application, while keeping your current notes and settings. It is not a backup of your notes. After returning to alpha.2, run the new installer to upgrade again.

Uninstall

Save, quit, then run:

notryn uninstall

The current app and launcher are removed. Your notes, connected folders and settings are kept. The old app is retained in a recoverable application-backup folder.

Windows

Not available yet. Linux comes first, then macOS. Windows will be listed here when a native package has passed testing.
